# Rustlings auf Deutsch 🦀

Eine deutsche Übersetzung der [Rustlings](https://github.com/rust-lang/rustlings)-Übungen —
kleiner Übungen, um dich an das Lesen und Schreiben von Rust-Code zu gewöhnen.

Dies ist eine inoffizielle Community-Übersetzung, gelistet (nach Aufnahme) auf der
offiziellen [Community-Exercises-Seite](https://rustlings.rust-lang.org/community-exercises)
von Rustlings. Struktur, Code und Tests entsprechen dem Original — übersetzt sind die
Aufgabenstellungen, Kommentare und Hinweise.

## Loslegen

1. [Installiere Rustlings über die offizielle Anleitung](https://github.com/rust-lang/rustlings)
   ✅
2. Klone dieses Repository, öffne ein Terminal in diesem Ordner und führe `rustlings`
   aus, um mit den Übungen zu starten 🚀

## Lizenz und Herkunft

Basiert auf dem Original-Projekt [rust-lang/rustlings](https://github.com/rust-lang/rustlings)
von Carol (Nichols || Goulding) und den Rustlings-Mitwirkenden, MIT-lizenziert (siehe
[`LICENSE`](LICENSE)). Diese Übersetzung übernimmt Struktur, Code und Tests unverändert
und steht unter derselben Lizenz.

**Hinweis:** Übersetzt werden die Aufgabenstellungen und Hinweise — nicht die
Fehlermeldungen des Rust-Compilers selbst. Die bleiben auch hier englisch.
